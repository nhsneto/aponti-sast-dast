# Aponti Academy - DevOps - SAST e DAST

Aplicação prática das ferramentas:

- **SAST** (Static Application Security Testing)
  - Analisa o código fonte, bytecode ou binários sem executar a aplicação
  - Identifica falhas lógicas e vulnerabilidades comuns no estágio de Code ou Build
- **DAST** (Dynamic Application Security Testing)
  - Testa a aplicação em tempo de execução simulando ataques externos;
  - Detecta vulnerabilidades que só aparecem quando o sistema está ativo.

## Objetivos

- Escolher ou criar uma pipeline no GitHub Action;
- Adicionar uma etapa *SAST* à pipeline;
- Adicionar uma etapa *DAST* à pipeline.
